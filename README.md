FoodFusion - Food Delivery Application

FoodFusion is a full-stack food delivery platform that allows users to browse food items, add them to the cart, place orders, and make secure payments.
It includes an admin dashboard for managing products, users, and orders efficiently.

Features

User Authentication – Secure login & signup with JWT (Spring Security)
Product Management – View, add, update, and delete food items (admin only)
Cart System – Add or remove items and view total price dynamically
Online Payments – Integrated Razorpay for real-time payment processing
Image Storage – Used AWS S3 for storing and retrieving food images
Admin Dashboard – Manage users, orders, and menu items
RESTful APIs – Built using Spring Boot and integrated with MongoDB
